# Agent Instructions: Next.js Frontend

## 🎯 Context
Next.js frontend application consuming the Go backend API.

## 💻 Code Standards
1. **Framework:** Next.js 14+ with App Router (`/app`). Strictly TypeScript (`.tsx`).
2. **Components:** Default to React Server Components (RSC). Only use `'use client'` when strictly necessary.
3. **Styling:** Tailwind CSS.
4. **Data Fetching:** Prefer server-side native `fetch`.
